# NASHALJ SITE

وب‌سایت فرهنگی و معرفی روستای نشلج در منطقه اردهال کاشان.

## ویژگی‌ها
- طراحی فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ
- بدون فریم‌ورک JavaScript؛ رابط کاربری با HTML، CSS و JavaScript ساده
- فونت Vazirmatn از Google Fonts و تصاویر از منبع خارجی بارگذاری می‌شوند
- ساختار معنایی HTML، دسترس‌پذیری پایه و پشتیبانی از کاهش حرکت
- فراداده‌های SEO و Open Graph، فایل manifest، robots و sitemap
- ناوبری موبایل، تغییر تم روشن/تیره و انیمیشن‌های ملایم بدون کتابخانه
- آماده انتشار مستقیم از ریشه مخزن با GitHub Pages

## اجرای محلی
فایل `index.html` را باز کنید یا از یک سرور استاتیک ساده استفاده کنید:

```bash
python -m http.server 8000
```

سپس به `http://localhost:8000` بروید.

## ساختار
- `index.html` محتوای اصلی و بخش‌های سایت
- `styles.css` طراحی، رنگ‌ها و واکنش‌گرایی
- `script.js` تعامل‌های کوچک رابط کاربری
- `assets/nashalj-mark.svg` نشان اختصاصی سایت
- `.nojekyll` جلوگیری از پردازش فایل‌ها توسط Jekyll
- `site.webmanifest` فراداده نصب وب‌اپ
- `robots.txt` و `sitemap.xml` اطلاعات خزنده‌های موتور جست‌وجو

## انتشار در GitHub Pages
این پروژه به build step نیاز ندارد. در مخزن به مسیر Settings → Pages بروید و این تنظیمات را انتخاب کنید:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- سپس Save را بزنید.

آدرس پروژه: https://sepehrirl.github.io/nashalj/

نکته: آدرس فایل‌های محلی عمداً نسبی هستند تا در مسیر پروژه‌ای GitHub Pages درست بارگذاری شوند. GitHub Pages هدرهای سفارشی مخصوص بعضی میزبان‌های دیگر را از فایل `_headers` اعمال نمی‌کند.
