# NASHALJ SITE

وب‌سایت فرهنگی و معرفی روستای نشلج در منطقه اردهال کاشان.

## ویژگی‌ها
- طراحی فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ
- بدون فریم‌ورک و وابستگی خارجی؛ بارگذاری سبک و سریع
- ساختار معنایی HTML، دسترس‌پذیری پایه و پشتیبانی از کاهش حرکت
- فراداده‌های SEO و Open Graph، فایل manifest، robots و sitemap
- ناوبری موبایل و اسکریپت کوچک بدون کتابخانه
- آماده میزبانی روی Cloudflare Pages یا هر میزبان فایل استاتیک

## اجرای محلی
فایل `index.html` را باز کنید یا از یک سرور استاتیک ساده استفاده کنید:

```bash
python -m http.server 8000
```

سپس به `http://localhost:8000` بروید.

## ساختار
- `index.html` محتوای اصلی و بخش‌های سایت
- `styles.css` طراحی، رنگ‌ها و واکنش‌گرایی
- `script.js` تعامل‌های کوچک رابط کاربری
- `assets/nashalj-mark.svg` نشان اختصاصی سایت
- `_headers` هدرهای امنیتی و کش برای میزبان‌های سازگار
- `site.webmanifest` فراداده نصب وب‌اپ

## انتشار
این پروژه به build step نیاز ندارد. برای Cloudflare Pages، مخزن GitHub را متصل و تنظیمات زیر را انتخاب کنید:
- Framework preset: None
- Build command: خالی
- Build output directory: /

## پیش از انتشار عمومی
- نشانی ایمیل نمونه `hello@nashalj.site` را با راه ارتباطی واقعی و مجاز جایگزین کنید.
- مالکیت و مجوز استفاده از تصاویر را بررسی و در صورت نیاز تصاویر اختصاصی جایگزین کنید.
- دامنه نهایی را در `robots.txt`، `sitemap.xml` و متادیتا هماهنگ کنید.
- متن‌ها و جزئیات تاریخی را با پژوهش میدانی و منابع معتبر محلی تکمیل کنید.
